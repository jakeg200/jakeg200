# web

The room. Next.js 15, canvas via `perfect-freehand`, pointer events with pressure where available.

```bash
npm install
npm run dev          # expects the API on :8000
```

Desktop with a stylus or trackpad. Mobile is a non-goal (SPEC.md §3).

M4 adds voice here: streaming STT in, TTS out, with barge-in — the tutor stops speaking the instant
the learner starts. Barge-in is not optional; without it the room feels like a lecture.
